# ORACLE API Endpoints

## Base URL

```text
http://localhost:8000
```

Interactive API documentation is available at:

```text
http://localhost:8000/docs
```

---

## Overview

The backend uses ORACLE to get structured, multi-perspective decisions from a set of expert agents:

- `climate` — climate and environmental analysis
- `economy` — economic and budget impact
- `health` — public health and medical outcomes
- `citizen` — ordinary citizen sentiment and equity implications
- `ethics` — ethical and moral assessment
- `judge` — synthesizes all perspectives into a final recommendation

The backend should call `/decide` when it needs a complete decision package for a problem.

## Create a Decision

```http
POST /decide
Content-Type: application/json
```

### Request body

```json
{
  "problem_description": "هل يتم تحويل أتوبيسات القاهرة إلى كهرباء؟",
  "user_input": "الميزانية محدودة والأولوية للصحة وجودة الخدمة.",
  "language": "Arabic",
  "memory_scope": "my-test"
}
```

### Request fields

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `problem_description` | string | Yes | The main decision problem or question. |
| `user_input` | string | No | Extra context to guide the agents. Defaults to an empty string. |
| `language` | string | No | Optional response language hint (e.g. `Arabic`, `English`). If omitted, ORACLE attempts to match the problem language. |
| `memory_scope` | string | No | Isolates memory for a user/group/context. Defaults to `default`. |

### Expected response (`200`)

```json
{
  "final_decision": "Proceed with a phased, equity-first electrification of Cairo's public bus fleet...",
  "decision_reasoning": "The expert perspectives converge on a strong consensus...",
  "final_confidence": 0.85,
  "climate_analysis": "...",
  "economy_analysis": "...",
  "health_analysis": "...",
  "citizen_perspective": "...",
  "ethics_evaluation": "...",
  "memory_matches": 3,
  "status": "success"
}
```

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `final_decision` | string | Final recommendation generated by the Judge Agent. |
| `decision_reasoning` | string | Synthesized reasoning behind the recommendation. |
| `final_confidence` | number | Confidence score between 0 and 1. |
| `climate_analysis` | string | Raw climate agent analysis text. |
| `economy_analysis` | string | Raw economy agent analysis text. |
| `health_analysis` | string | Raw health agent analysis text. |
| `citizen_perspective` | string | Raw citizen agent perspective text. |
| `ethics_evaluation` | string | Raw ethics agent analysis text. |
| `memory_matches` | integer | Number of prior relevant memory entries used as context. |
| `status` | string | `success` when the request completed successfully. |

### How the backend should use the response

1. Save the full response in logs or decision history.
2. Show `final_decision` and `decision_reasoning` to the user.
3. Optionally display the per-agent analyses as supporting details.
4. Use `memory_matches` to know if historical context affected the decision.

---

## Agent Communication Model

### What the backend sends

The backend sends a single decision request to ORACLE using `/decide`. ORACLE internally runs all domain agents in parallel and then passes their outputs to the Judge Agent.

### What ORACLE returns

ORACLE returns a fully assembled decision package with both:

- `final_decision`, `decision_reasoning`, and `final_confidence` from the Judge Agent
- raw analysis strings from each domain agent to help explain the result

---

## Error Responses

| Status | Meaning |
| --- | --- |
| `422` | Invalid request body, such as missing `problem_description`. |
| `503` | The LLM provider is not configured, or the graph is unavailable. |
| `500` | The internal decision workflow failed unexpectedly. |

## cURL Example

```bash
curl -X POST http://localhost:8000/decide \
  -H "Content-Type: application/json" \
  -d '{
    "problem_description": "Should Cairo convert its bus fleet to electric vehicles?",
    "user_input": "The budget is limited and priority is health and service quality.",
    "language": "Arabic",
    "memory_scope": "my-test"
  }'
```
